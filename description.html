BrewPoint Order Counter

Project Statement

Karthik is a frontend developer at BrewPoint Technologies, a company that builds billing and ordering software for coffee shops. His team lead, Anitha, has assigned him a task to build an Order Counter where a cashier can increase or decrease the quantity of each menu item and view the final order summary on a separate page.

Anitha tells Karthik:

"The menu quantities must be controlled from the App component itself, not inside each row. Keep the menu list in useState inside App, pass each item's quantity down as props along with two handler functions, and use useEffect to log the total item count whenever it changes. The MenuItem component must be a presentational component that only receives props and calls the handlers. Add routing so the cashier can switch between the Menu page and the Summary page, and the summary must show the calculated total amount."

Karthik must complete the task using React with State, Props, PropTypes, Hooks (useState, useEffect), Routing (react-router-dom) and Styling.

Component Details

App.js

  • Imports and renders the MenuItem and OrderSummary components
  • Uses the useState hook to hold the menu list as an array of objects, initialized to:
    • { id: 1, itemName: "Espresso", category: "Hot", price: 120, quantity: 0 }
    • { id: 2, itemName: "Cold Brew", category: "Cold", price: 180, quantity: 0 }
    • { id: 3, itemName: "Cappuccino", category: "Hot", price: 150, quantity: 0 }
  • Calculates two derived values on every render:
    • totalItems → the sum of all quantity values
    • totalAmount → the sum of price * quantity for every item
  • Uses the useEffect hook that runs whenever totalItems changes:
    • Logs to console the single message: Total items in cart: followed by the value of totalItems (for example: Total items in cart: 3)
    • Dependency array must include totalItems
  • Defines two handler functions:
    • handleIncrease(id) → increases that item's quantity by 1
    • handleDecrease(id) → decreases that item's quantity by 1, but never below 0
  • Wraps the whole application inside a Router (BrowserRouter from react-router-dom)
  • Renders a div with id="app-container"
  • Inside it renders:
    • A h1 with id="page-title" → displays text: BrewPoint Order Counter
    • A span with id="total-items" → displays text: Total Items: followed by the value of totalItems
    • A nav with id="main-nav" containing two Link elements:
      • Link to "/" → displays text: Menu
      • Link to "/summary" → displays text: Summary
    • Routes with two routes:
      • Path "/" → renders a div with id="menu-list" that renders a MenuItem for each item, passing itemName, category, price, quantity, onIncrease, onDecrease as props and key → item.id
      • Path "/summary" → renders the OrderSummary component, passing orderedItems (only the items whose quantity is greater than 0) and totalAmount as props
  • The page title, total items badge and nav must stay visible on both routes (they are rendered outside Routes)
  • Imports App.css for styling

MenuItem.jsx

  • Presentational functional component with no state of its own — it receives itemName, category, price, quantity, onIncrease and onDecrease as props
  • Renders a div with className="menu-row"
  • Inside it renders a div with className="item-info" containing:
    • A h2 with className="item-name" → displays the value of itemName
    • A p with className="item-category" → displays text: Category: followed by the value of category
    • A p with className="item-price" → displays text: Price: $ followed by the value of price
  • Then renders a div with className="qty-controls" containing, in order:
    • A button with className="decrease-btn" → button text: - → on click calls onDecrease
    • A span with className="qty-value" → displays the value of quantity
    • A button with className="increase-btn" → button text: + → on click calls onIncrease
  • Uses PropTypes to validate:
    • itemName → PropTypes.string.isRequired
    • category → PropTypes.string.isRequired
    • price → PropTypes.number.isRequired
    • quantity → PropTypes.number.isRequired
    • onIncrease → PropTypes.func.isRequired
    • onDecrease → PropTypes.func.isRequired
  • Imports MenuItem.css for styling

OrderSummary.jsx

  • Functional component rendered by the /summary route, receiving orderedItems and totalAmount as props
  • Renders a div with id="order-summary"
  • Inside it renders:
    • A h2 with id="summary-title" → displays text: Order Summary
    • When orderedItems is empty → a p with id="empty-order" → displays text: No items ordered yet.
    • When orderedItems is not empty → a ul with id="summary-list" containing one li with className="summary-row" per ordered item, displaying the item name, then x , then the quantity, then = $, then the line total (price * quantity) — for example: Espresso x 2 = $240
    • A p with id="total-amount" → displays text: Total Amount: $ followed by the value of totalAmount
  • Uses PropTypes to validate:
    • orderedItems → PropTypes.array.isRequired
    • totalAmount → PropTypes.number.isRequired

  • Decreasing a quantity that is already 0 must leave it at 0

  • No JSON Server or API calls — the menu data is hardcoded in App.js state

  • useEffect must include totalItems in its dependency array
  • Routing must be implemented with react-router-dom (BrowserRouter, Routes, Route, Link)

Platform Instructions to Run the Application

Open the terminal and follow the steps below:

Step 1: Use cd reactapp command to navigate to the reactapp directory.

Step 2: Use nvm use 16 command to choose the node version.

Step 3: Use npm i command to install the node_modules.

Step 4: Use npm start command to start the application.

Note

  • Click PORT: 8081 to view the output.
  • Click Run Test Case button to run the test cases.
  • If any error persists while running the app, delete the node_modules and reinstall them.
  • Do not rename or remove any existing id, className, text wording, or file from the skeleton — the testcases rely on the exact structure described above.
